    How to use the map

    Start at a glowing node.

    Glowing nodes are your frontier: everything they need, you have already proven. Open one, write an attempt at its check, rate your confidence, then reveal the answer. A correct answer marks the node mastered, and new nodes start to glow.

    Red dashed nodes are misconceptions. Try those first: a wrong answer there tells the agent to teach for conceptual change, not just add more facts.

    Your progress stays in this browser. Export it as learner.json and run python scripts/dulta.py frontier --state learner.json.
