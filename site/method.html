Method

DADA's principles, rebuilt for the classroom.

DultA was written from scratch, not forked. It keeps every principle of DADA and its variants (P-DADA, 3DADA, PMDAA) and changes what is being worked on: a learner's understanding, or the teaching that will build it.

DADA principleIn DultA
A living frontier over an anchor graphTwo graphs: the pedagogy anchor graph below, and a domain map. The learner frontier is Knowledge Space Theory's outer fringe: every node not yet mastered whose prerequisites are.
KEEP-THE-RULE versus BREAKConsolidate (worked example, retrieval, spacing) versus Cross (a threshold concept, a productive failure, a cognitive conflict).
Dotted counterpointsMisconceptions in the domain map, and rival theories in the anchor graph. Every misconception attached to a node in use is probed or declined.
Measure the move, never assume itMastery means an unaided answer with a confidence rating, never "I get it". Courses are measured by normalized gain and an alignment audit.
One subagent per literary reference34 seats, each argued from a single learning scientist's own work: Vygotsky, Sweller, Bjork, Kapur, Biggs, Hake, hooks, Bastani and more. Zheng (judge bias) and Liu (context limits) are required whenever the learner is an agent.
Measure, don't trust fluencyThe learner can be a person or an AI agent. An agent counts as having learned only when a fresh agent, given just the notes, passes held-out checks graded by a separate agent. dulta.py quiz keeps answer keys apart, and dulta.py leak catches answers that slip into the notes.
A verdict is a fileEach seat writes to panel/R<n>/<seat>.md, and dulta.py panel lists who reported.
Re-measure what the artifact printsEvery score, gain or count shown to a learner is recomputed at the final state. The numbers on this site are computed from the same map data the command line reads.
SSOTmaps/*.json is the only record of the content. Every diagram, and this website, is generated from it.
Five artifacts

A run only counts once it is written down.

Every session appends to LEARNING-LOG.md. A commit message is not a decision record, and "considered Kapur" is not a panel.

  1. Traversal Plan and FrontierMode, domain map, diagnosis, seed anchors, and the live frontier table.
  2. Decision RecordsWritten before each move: anchors, Toulmin argument, rejected options, load count, the fence being crossed, and the learner evidence or exit test.
  3. Panel ReportsThe Critical Response Process. Every seat quotes the evidence it judged. Any seat may pull the Andon.
  4. Anchor and Map LedgerKEEP, ADAPT or SCRAP for each anchor. MASTERED, REOPENED or PROBING for each node, with the check and its date.
  5. Compliance CheckEach line points to where it was satisfied, and anything skipped is named.
Stop conditions

Bounded, but never stalled.

There is no lesson quota. The run ends when S1 to S5 hold. Hard caps stop it from looping forever: 3 ADAPT rounds per move, 6 WHOLE rounds per session, 3 retries per seat. When the critics start repeating themselves, it ships the strongest version and logs what is still open.

S1

Frontier closed

No OPEN items in scope. Each one is TAKEN or DEFERRED with a reason.

S2

Panel passes

A WHOLE round where every required seat passes and no Andon is pulled.

S3

Saturation

Two WHOLE rounds in a row that change nothing.

S4

Ambition push

A far-transfer problem, or the hardest outcome raised one level, with the result measured.

S5

Misconceptions

Every dotted edge on a node in use is probed or declined.

Command line

The tooling the skill calls.

Standard-library Python with no dependencies. Validate the maps, render diagrams and site data from them, compute a learner's frontier, print quizzes with the answer key kept separate, check agent notes for leaked answers, compute normalized gain, audit course alignment, and collect panel verdicts.

python scripts/dulta.py validate
python scripts/dulta.py render
python scripts/dulta.py frontier --state learner.json --map physics
python scripts/dulta.py quiz --map embedded --nodes gpio,timing --key key.md
python scripts/dulta.py leak NOTES.md
python scripts/dulta.py gain --pre 42 --post 71
python scripts/dulta.py align examples/course.json
python scripts/dulta.py panel panel/R1 vygotsky bjork kapur
