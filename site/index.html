Learn at the edge of what you know.

DultA is an agent skill for teaching people and teaching AI agents. It keeps a map of the subject, finds the frontier just beyond what the learner has proven, and won't call anything learned until it is answered unaided. For an agent, that means a fresh agent with only the notes. Every move is argued in writing and judged by a panel of learning scientists.

Domain maps

Ten subjects, drawn as graphs you can walk.

Each node has an outcome, a retrieval check and an answer. Solid edges are prerequisites. Dotted red edges are the misconceptions that block a concept. Amber nodes are threshold concepts: once crossed, the subject looks different.

The loop

No quota. It stops when the evidence says stop.

The traversal is DADA's: a living frontier instead of a syllabus, a decision record before every move, an independent panel after it, and stop conditions instead of a lesson count.

  1. DiagnoseRetrieval checks and a misconception probe before any teaching.
  2. FrontierThe outer fringe of the map: nodes whose prerequisites you have proven.
  3. DecideA written record: anchors, argument, rejected options, load count.
  4. MoveConsolidate (examples, retrieval) or Cross (a threshold, a productive failure).
  5. MeasureYour unaided answer and confidence. Nothing else counts as mastery.
  6. PanelOne subagent per learning scientist, each citing your actual answers.
  7. ReopenFailed checks and spaced reviews return to the frontier.
Two modes

For the learner, and for the teacher.

Mode 1

Directed Learning

Just beyond reach, proven by retrieval.

The agent tutors a learner across a domain map. Every move targets the frontier, and a node is mastered only on an unaided answer with a confidence rating.

  • Required seats: Vygotsky, Bjork, Kapur, Sweller, Bastani
  • Extra field: learner evidence (check, answer, confidence)
  • Ambition push: a far-transfer problem from another map
Mode 2

Directed Teaching

Aligned and measured.

The agent designs a course, lecture, lab or assessment. Every outcome has an activity and an assessment that measures it, and the course states how gain is measured.

  • Required seats: Biggs, Wiggins, Hake, Wieman, hooks, Rose
  • Extra field: exit test (the item and its threshold)
  • Ambition push: raise the hardest outcome one level
Learning best with agents

An agent that will not do your thinking for you.

In a field experiment, students given unguarded chatbot help scored higher in practice and lower on the exam. A hint-only tutor removed the harm. DultA is built on that result.

  1. Generation before helpYou commit an attempt and a confidence rating before the agent says anything substantive.Slamecka & Graf, The Generation Effect
  2. Climb the hint ladderA question, then a pointer, then a sub-goal, then one step. The full answer comes last, followed by a fresh problem.Pólya; Cognitive Tutors; Bastani et al.
  3. Four new things at mostEach explanation counts its new terms and symbols. The cap is four.Cowan, The Magical Number 4
  4. Probe before teaching overA concept with a known misconception starts with the probe. A wrong answer turns the move into a Cross.Posner et al., Conceptual Change
  5. Explain-back closes a nodeYou explain it in plain words. Wherever you reach for jargon, there is a gap.Feynman Technique
  6. Spaced reopeningMastered nodes return after 1, 3, 7, 16 and 35 days, or right away if a later check fails.Ebbinghaus; Leitner
  7. Fluency is not evidenceAn explanation that sounds clear is only a guess about the learner. Their answer is the test.Bjork, Desirable Difficulties
Two kinds of learner

Teach a person. Teach an agent. Same maps, same proof.

An agent's weights don't change during a session. It learns through what goes into its context, and through notes written down for the next agent. So for an agent, "learned" means a fresh agent with only those notes passes questions it has never seen, graded by a separate judge.

Human learner

Learning lives in memory.

  • Diagnosis: retrieval checks and misconception probes in conversation
  • Help only after an attempt and a confidence rating
  • Mastery: an unaided answer; spaced reviews reopen it later
  • Progress kept in learner.json
Agent learner

Learning lives in the notes.

  • Baseline: a fresh subagent answers dulta.py quiz cold
  • The tutor revises the notes or skill file, never pasting answers
  • Mastery: a fresh agent with only the notes passes held-out checks, graded by a separate agent
  • dulta.py leak catches answer keys hiding in the notes
Labs

Predict first. Then run it.

Each lab follows Predict–Observe–Explain. The simulation stays locked until you commit a prediction, and the explanation stays locked until you have seen how far off you were.
