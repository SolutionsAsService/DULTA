Career tracks

Pick a job. See the path to it.

Each track is an ordered path through nodes from several maps, ending in a capstone project. Progress comes from the same checks you answer on the maps, so a node mastered on one track counts on every track that uses it. Tracks are suggestions: the maps stay fully open.

Tracks live in tracks/careers.json and are checked by python scripts/dulta.py validate.
